# Dupilumab: meccanismo d'azione in 3D

Modello 3D interattivo che spiega come dupilumab (Dupixent) blocca la segnalazione di IL-4 e IL-13 legandosi al recettore IL-4Rα.

A cura del **Dott. Francesco D'Aniello** · [studiotecnicodaniello.com](https://studiotecnicodaniello.com/) · [LinkedIn](https://www.linkedin.com/in/francesco-d-aniello-010b12154/)

## Come funziona

- Pagina unica (`index.html`), nessun passaggio di build.
- All'apertura scarica le strutture cristallografiche dal Protein Data Bank (6WGL, 3BPL, 3BPO), le sovrappone nel browser e calcola contatti e ingombri sterici.
- Librerie da CDN: Three.js r128 (animazione) e 3Dmol.js 2.5.3 (visualizzatore atomico).
- Lingue: italiano e inglese (pulsante IT/EN, oppure `?lang=en` nell'indirizzo).

## Pubblicazione

Il repository è collegato a Netlify: ogni modifica caricata sul ramo `main` viene pubblicata automaticamente.
